### MERN Stack E-commerce Application

Developing a full-stack e-commerce web application using the MERN stack, featuring a customer-facing storefront, an admin dashboard, and a RESTful backend API.

Implemented a responsive user interface with React.js, Vite, and Tailwind CSS, along with dynamic routing using React Router DOM. Integrated Redux Toolkit and Redux Persist for global state management and persistent shopping cart functionality.

The backend is built with Node.js and Express.js, using MongoDB and Mongoose for database management. Implemented JWT-based authentication and admin authorization, with Multer and Cloudinary for product image uploads.

**Key Features:**
- Responsive customer storefront and admin dashboard.
- Dynamic product listing and product details.
- Shopping cart management with Redux Toolkit.
- User registration and login with JWT authentication.
- Admin product and user management.
- Product image uploads using Cloudinary.
- RESTful API integration using Axios.
- Persistent cart and application state using Redux Persist.

**Technologies:** React.js, Vite, Tailwind CSS, JavaScript (ES6+), Redux Toolkit, Redux Persist, React Router DOM, Node.js, Express.js, MongoDB, Mongoose, JWT, Multer, Cloudinary, Axios.
